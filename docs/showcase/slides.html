1. Why Single-Service CI Passed & Production Returned HTTP 500

Four Realistic Cross-Service Incidents

  • INC-101 (Stacked Promo Negative Subtotal): SAVE20 + FLAT15 on a $16.00 cart drives subtotal to -220 cents across Python and Go.
  • INC-102 (Flash-Sale Bundle u32 Underflow): Rust u32 subtraction panics when bonus_bundle_units exceeds remaining stock.
  • INC-103 (Zero-Decimal JPY Rounding): Fractional minor units (4476.15) rejected across TypeScript, Python, and Go.
  • INC-104 (Lithium Hazmat Weight Tier): UN3480-LITHIUM ground parcel at 3,400g hits unhandled carrier boundary.

4. Recursive Task-Tree Fan-Out & Red-Green TDD (BOM-20)

Selective Blast-Radius Orchestration

  • Root Task (triage-<id>): Queries Loki LogQL stack traces and fans out Child Tasks only for the 2 to 3 implicated services.
  • Child Task (fixer-<id>-<svc>): Writes a failing regression test first (Red), synthesizes the minimal patch (Green), and pushes refs/heads/fix/<task>.
  • Self-Suspend Reclamation: Calls SuspendTask inside OnCommandExit to free the gVisor slot in 61ms.
