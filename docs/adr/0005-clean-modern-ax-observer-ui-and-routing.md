# Clean Modern AX Observer UI with Path-Based Routing

We design the `AX Observer` (`:3000`) as a clean, modern, uncluttered web interface with exact HTML5 History API path-based routing (`/`, `/workers`, and `/about`, normalizing trailing slashes, returning `404` on unknown subpaths, and forbidding `?view=` query parameters), a top-right icon-only Moon/Sun Projector Light Mode toggle with zero layout shift, `Execution Mode` (`LIVE_GKE` | `SIMULATED`) and `Source Provenance` (`LIVE` | `FIXTURE`) header pills, a discrete `⌘K` Incident Scenario & Harness modal, a Go-backed interactive `/about` `Architecture Topology Catalog` (`ADR-0010`), and direct external links to the standalone Retail Storefront (`:3001`) and Grafana (`:3002`).
