# Clean Modern AX Observer UI with Path-Based Routing

We design the `AX Observer` (`:3000`) as a clean, modern, uncluttered web interface with path-based routing (`/`, `/workers`, `/about`), a top-right icon-only Moon/Sun Projector Light Mode toggle with zero layout shift, a discrete `⌘K` Incident Scenario & Harness modal, and direct external links to the standalone Retail Storefront (`:3001`) and Grafana (`:3002`).
