# Polyglot Five-Service Storefront, Incident Catalog, and Pre-Warmed Git Rollouts

We structure the target application as a 5-service polyglot retail monorepo (`storefront-web` in Node.js/TypeScript, `checkout-service` in Go, `shipping-service` in Go, `pricing-service` in Python/FastAPI, and `inventory-service` in Rust/Axum) backed by an in-cluster Git server (`baseline-v1` baseline tag) and pre-warmed language build caches (`cargo` + `/opt/cargo-target`, `GOCACHE`, `venv`, `node_modules`) managed per pod by a `Hot-Reload Supervisor` (`ADR-0009`) so triggering any of the 4 real latent multi-service Incident Scenarios (`INC-101` through `INC-104`), rolling out verified agent fixes selectively by `git diff`, and resetting back to `baseline-v1` complete in under 10 seconds (`< 3s` typical).
