# Interactive `/about` Architecture Topology Catalog and Automated Drift Verification

Instead of hardcoding static architecture diagrams in HTML where labels silently drift behind runtime changes, `/about` in `AX Observer` renders entirely from a stateless, strongly typed `GET /api/about/catalog` (`ArchitectureTopologyCatalog`) endpoint backed by live Go registries (`storefront.AllServices()`, `storefront.ListScenarios()`, `gateway.DefaultFallbackCascade`, Coding Harnesses, and task/sandbox lifecycle stages) and guarded in `go test` by `VerifyArchitectureCatalogDrift`, which inspects `docs/adr/00*.md` on disk alongside non-overlapping SVG `viewBox` bounding boxes and edge/pulse referential integrity. The `/about` view presents a stage-safe live status strip (scrubbed of cluster, project, node, or bucket identifiers) above a read-only 3-tab interactive SVG workspace (`3-Surface Mesh & Incident Pulse Simulator`, `Recursive Task-Tree & SuspendTask Slot Simulator`, and `Coding Harnesses, Gemini Cascade & ADR Map`) styled purely with CSS custom properties for zero-layout-shift Projector Light Mode parity, where `"Launch in Bug Bash Tree →"` navigates via `pushState("/")` and pre-selects the chosen scenario and harness inside the `⌘K` modal for deliberate 1-click confirmation rather than auto-firing production alerts.
