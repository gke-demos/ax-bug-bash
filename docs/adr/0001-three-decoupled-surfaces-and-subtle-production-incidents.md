# Three Decoupled Surfaces and Subtle Production Incidents

We decouple the demo into three independent, authentic production surfaces (a standalone 5-service polyglot **Retail Storefront** in `Node.js`, `Go`, `Python`, and `Rust`, an **Off-the-Shelf Monitoring & Alerting Stack**, and a dedicated **AX Observer**) instead of embedding the storefront inside a monolithic dashboard. Furthermore, pre-existing unit and integration tests pass before an incident occurs: incidents are triggered by subtle runtime edge cases not covered by existing tests, requiring each Child AX Task to author a new failing regression test from the alert telemetry before patching and redeploying only the affected microservices.
