# Multi-Harness Sandbox and Gemini Flash Fallback Cascade

We bundle three CLI coding harnesses—**Antigravity** (`google-antigravity`), **OpenCode** (`opencode-ai`), and **Pi** (`@mariozechner/pi-coding-agent`)—inside `Dockerfile.task-runner` and route all model requests through a zero-secret in-cluster **Agent Platform Model Gateway** (`http://model-gateway.ax-system:8080/s/{task_name}`) exposing both native Gemini REST (`/v1beta/models/...`) and OpenAI-compatible (`/v1/chat/completions`) endpoints. The Model Gateway enforces an ordered Gemini model fallback cascade of **`gemini-3.8-flash` → `gemini-3.7-flash` → `gemini-3.6-flash` → `gemini-3.5-flash`** (with deterministic `FIXTURE` fallback for offline/CI test runs), and `Task.spec.config` allows selecting a single harness or assigning `antigravity`, `opencode`, and `pi` across sibling Child AX Tasks in parallel.
