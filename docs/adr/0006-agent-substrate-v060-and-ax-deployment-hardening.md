# Agent Substrate v0.6.0 and google/ax Deployment Hardening

We bake four verified Agent Substrate `v0.6.0`/`v0.6.1+` and `google/ax` runtime mitigations directly into our control-plane overlay, manifests, and custom runner: (1) a global OpenFGA `AccessPolicy` (`--global`) granting `user:system:serviceaccount:ax-system:ax-server` `role: owner` so `CreateAtespace` succeeds (`Issue #511`), (2) storing custom-runner state under `/workspace/.ax-state/<task-name>.json` and `workspace.AXDir = "/workspace/.ax"` with idempotent `--execute-task` short-circuiting so `SNAPSHOT_FIDELITY_VOLUMES` preserves state across suspend/resume (`Issue #518`), (3) setting `ActorTemplate` `WakeupProbe` to `/healthz` with `GOLDEN_SNAPSHOT_MODE_DISABLED` and attaching a least-privilege per-actor `EgressPolicy` before `ResumeActor` so `atenet-egress` allows sub-second in-cluster `git clone` prior to `/readyz` (`Issue #482`), and (4) wrapping `ax-server` `SuspendTask` in `context.WithoutCancel` so self-referential `OnCommandExit` → `SuspendTask` calls survive caller gVisor teardown.
